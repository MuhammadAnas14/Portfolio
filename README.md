# muhammadanas

Personal portfolio of Muhammad Anas, Full-Stack Engineer in Passau, Germany.

Built with Next.js 15, Tailwind CSS 4 and Motion, deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

All text lives in `data/content.ts`: profile links, impact numbers, story, experience, projects and stack.

- **Photo:** put the image at `public/photo.jpg` and set `photo: "/photo.jpg"` in `data/content.ts`.
- **Resume:** replace `public/Muhammad_Anas_Resume.pdf`.

Every push to `main` deploys automatically on Vercel.
